# Fx Language Features for VS Code

This is an extension that gives VS Code language features for Triflare Fx. This guide will be kept short, here's how to install it:

## Installation

1. Install the extension's dependencies:

   ```bash
   npm i # make sure you're in editors/vscode
   ```

2. Now, build the extension:

   ```bash
   npm run build
   ```

3. Now, right-click the generated .vsix file, then click **"Install Extension VSIX."**
